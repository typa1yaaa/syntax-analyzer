# Syntax Analyzer для музыкальных запросов

Синтаксический анализатор для естественно-языковых запросов к музыкальной базе данных на русском языке.

**Задание:** разработать формальную грамматику для предметно-ориентированного языка (DSL - Domain-Specific Language) запросов к базе данных и реализовать синтаксический анализатор, строящий деревья разбора для корректных выражений.

Проект реализует полный алгоритм обработки пользовательских запросов: от лемматизации слов через классификацию токенов до синтаксического разбора с построением дерева запроса.  
Подробное описание реализации проекта приведено в [документе с реализацией](https://docs.google.com/document/d/1K_cU0X7n1Ga0OzkSN_ECGJhz6k1NjuvnXHB2Yaqx5MU/edit?usp=sharing).

## Описание

Этот проект решает задачу парсинга музыкальных запросов пользователя и преобразования их в структурированные синтаксические деревья.

## Архитектура

Проект состоит из трех основных этапов:

1. Лемматизация  
   Входная строка приводится к нормальной форме. Для каждого слова определяется лемма и часть речи.

2. Классификация токенов  
   Каждое слово сопоставляется с категорией DSL, например: `VERB`, `ITEM`, `YEAR`, `GENRE`, `QUANTIFIER`.

3. Синтаксический разбор  
   На основе классифицированных токенов строится дерево запроса. Если порядок слов или структура запроса нарушены, парсер возвращает ошибку.

## Структура файлов

- `additional_lemma_func.py` — дополнительные функции для загрузки модели лемматизатора и обработки текста.
- `main.ipynb` — основной файл с реализацией лемматизации, классификации и парсера.
- `test.txt` — набор тестовых запросов, включая корректные и некорректные примеры.

## Использование

Основной сценарий работы:
1. загрузить модель лемматизатора;
2. обработать входной запрос;
3. классифицировать токены;
4. передать результат в парсер;
5. получить дерево разбора или сообщение об ошибке.

## Тестирование

В файле `test.txt` собрано 81 тестовое выражение. Они используются для проверки:
- корректной работы лемматизатора;
- точности классификации;
- правильности синтаксического разбора;
- обработки некорректных запросов.
